# Detail logique interne

## Structure

- `backend/` moteurs, algorithmes, automates serveur.
- `frontend/` logique client, états UI, flux d'interaction.
- `db/` modèle Prisma et transactions métier.
- `network/` cartographie HTTP/WebSocket.

## Convention

- Peu de texte, priorité aux schémas Mermaid.
- Un fichier = un moteur/élément logique.
