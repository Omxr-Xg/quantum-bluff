🚀 DÉMARRAGE (5 MINUTES)
═════════════════════════════════════════════════════════════════════════════

1. Appliquer la migration Prisma:
   $ cd server
   $ npx prisma migrate deploy

2. Recompiler le backend:
   $ npm run build

3. Redémarrer le serveur:
   $ npm run dev:server

4. Intégrer le composant:
   import { FreeRechargeButton } from '@/components/FreeRechargeButton'
   <FreeRechargeButton onClaimed={setBalance} />

5. Tester en navigateur:
   ✓ Voir le bouton doré
   ✓ Cliquer pour recharger
   ✓ Voir le compteur de cooldown
